## 本次修复

- 默认搜索恢复为必应网页搜索，在 GeckoView 内打开；主页可切换百度、Google、自定义 SearXNG，并保存选择。
- 中文和包含 `+`、`&`、`#` 的关键词正确编码。
- 明确输入的搜索结果网址直接打开，不再被拦截回 Cheems Search，消除原生搜索与网页搜索互相跳转。
- 修正 `target=_blank` / `window.open` 的新标签生命周期：向 Gecko 返回未打开的会话，由 Gecko 完成打开。
- 网页加载、重定向时不再盖回主页。保留错误恢复按钮，修复主页返回网页后前进/后退状态。
- SearXNG 仅在主动选择时使用，未配置服务器立即提示；不再默认依赖 priv.au。超时后的旧请求不会覆盖当前界面。
- 从仓库中的 `browser/` 工程直接构建，不再逐层改写 ZIP 源码；发布 APK 与验证记录绑定同一个提交。

## 验证与限制

发布流程要求 JVM 单元测试、Android 35 x86_64 模拟器回归测试和 ARM64 APK 检查全部通过。模拟器使用本地测试网页验证中文渲染、新标签、导航及错误恢复；外部搜索服务的可达性仍取决于手机网络，未在用户的 iQOO 实机上测试。

这是 ARM64 调试签名测试版。若覆盖安装提示签名不一致，需要先备份个人数据再卸载旧测试版。SearXNG 后端仍需自行配置；本版没有部署新的独立搜索服务器，也没有实现独立网页索引。

下载 `CheemsBrowser-v0.2.7-arm64.apk`。`SHA256SUMS.txt` 为校验值，`source-commit.txt` 记录构建源码版本。

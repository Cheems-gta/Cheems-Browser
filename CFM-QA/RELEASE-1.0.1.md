Cheems File Manager PC V1.0.1 修复预览版

- 修复跨盘文件夹移动；回收站共用完整复制后再删除源的实现，提前保存恢复索引。
- 复制和移动支持保留两份、跳过、覆盖整个项目，策略适用于整批操作。
- 复制、移动、CFM 回收和恢复、永久删除显示成功/失败明细。
- 文本保存写入同目录临时文件，刷新到磁盘后原子替换；保留一份 .cfm.bak。
- 工具栏换行，窄窗口上下布局，保留双栏、多选、图标及原有工具。

发布由 Windows CI 的文件系统、界面交互和 Edge 布局测试通过后执行。
仍需实机验证嵌入式 WebView2 与外部系统分享等交互。未增加代码签名、大目录虚拟滚动、回收站配额或自动备份过期清理。
覆盖文件夹会替换整个目标项目，不是合并。默认保留两份。
